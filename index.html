About

A developer's eye, a tester's discipline.

I'm Hadil, a QA Engineer and Software Engineer based in Tunis. I graduated from ESPRIT in 2026 after a nine-month final-year internship in Quality Assurance at Finserv, where I designed and executed test cases against real business requirements, tested APIs, and reported bugs in Agile sprints.

Before that I built software: a SharePoint Framework web part inside Microsoft 365, and an educational content management system as a full-stack developer. That background in Spring Boot, Angular and microservices means I understand how a feature is built, so I know where it usually breaks.

What I care about is simple: reliable digital products, clear bug reports developers can act on immediately, and test coverage that reflects how people actually use the software. My next step is growing into test automation and becoming the QA specialist a team relies on.

How I test a feature
01

Understand the requirement

Read the user story and acceptance criteria, ask the questions nobody asked yet, and map the risky paths.

02

Design the test cases

Positive, negative and edge cases, written so anyone on the team can execute them and get the same result.

03

Execute, at the UI and the API

Functional and regression runs through the interface, plus direct API checks for status codes, payloads and error handling.

04

Report, verify, close

Reproducible bug reports with steps, expected vs. actual and evidence, then re-testing the fix before it is marked done.
